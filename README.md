# Practical 5: Registration Form with Frontend Validation and User-Friendly Error Handling

## Practical Purpose
This practical is designed to demonstrate client-side form validation and user-friendly error handling using HTML5 and modern JavaScript.

## What This Practical Is For
* Creating a student registration form with proper HTML5 input types.
* Validating user inputs using Regular Expressions (Regex) for:
  - Full Name
  - Email Address
  - Mobile Number
  - Password and Confirm Password
  - Course and Year selection
  - Gender selection
  - Terms and Conditions acceptance
* Checking password strength dynamically.
* Displaying real-time validation error messages near respective fields.
* Ensuring accessibility with keyboard navigation and screen-reader-friendly labels.
